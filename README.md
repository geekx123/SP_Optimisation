# SP_Optimisation

Self-Potential Anomaly Detection – A geophysical signal-processing workflow for identifying subsurface conductive bodies using SP data. Includes filtering, baseline correction, anomaly extraction, Particle Swarm Optimisation and charge occurrence probability (COP) analysis. Implements forward modeling, inversion concepts, and anomaly localization for groundwater and planetary exploration. Built using Python and NumPy for rapid geoelectric interpretation.
